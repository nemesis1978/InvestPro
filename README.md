> Una piattaforma moderna per il monitoraggio e l'analisi di portafogli di investimento multi-asset.

## 📋 Panoramica

InvestPro è una piattaforma web che aiuta investitori retail e consulenti finanziari a monitorare, analizzare e ottimizzare i propri portafogli attraverso insight data-driven e strumenti di automazione.

## ✨ Funzionalità

- **Dashboard interattiva** con visualizzazione del portafoglio
- **Analisi avanzata** di asset allocation e performance
- **Alert personalizzabili** per eventi di mercato
- **Simulatore "what-if"** per strategie di investimento
- **Reportistica** scaricabile in PDF

## 🚀 Come iniziare

### Prerequisiti

- Node.js 18+
- pnpm (consigliato) o npm
- Git

### Installazione

```bash
# Clona la repository
git clone https://github.com/nemesis1978/InvestPro.git
cd InvestPro

# Installa le dipendenze
cd apps/web
pnpm install

# Avvia l'ambiente di sviluppo
pnpm dev
```

## 🏗 Struttura del progetto

```
InvestPro/
├── apps/
│   └── web/               # Applicazione web principale (Next.js/React)
├── packages/
│   ├── ui/                # Componenti UI condivisi
│   └── api/               # Client API e tipi condivisi
├── docs/                  # Documentazione
│   └── architecture/      # Documenti architetturali
└── scripts/               # Script di utilità
```

## 🛠 Sviluppo

### Comandi principali

```bash
# Esegui i test
pnpm test

# Esegui il linting
pnpm lint

# Avvia lo sviluppo
pnpm dev

# Build per produzione
pnpm build
```
