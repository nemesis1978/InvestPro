# Piano di Ricerca: Piattaforma di Investimenti

## Obiettivi
- Analizzare web app di riferimento per comprendere struttura e funzionalità
- Identificare API finanziarie gratuite e affidabili per dati di mercato
- Studiare l'algoritmo di Markowitz per ottimizzazione portafoglio
- Valutare tecnologie frontend per grafici e dashboard interattive

## Domande Chiave
1. Quali sono le funzionalità core della web app di riferimento?
2. Quali API finanziarie offrono il miglior rapporto qualità/prezzo per dati real-time?
3. Come implementare correttamente l'algoritmo di Markowitz in Python?
4. Quali librerie JavaScript garantiscono la migliore UX per grafici finanziari?

## Deliverable Attesi
- Report di analisi della web app esistente
- Comparazione dettagliata delle API finanziarie disponibili
- Guida implementativa dell'algoritmo di Markowitz
- Raccomandazioni tecnologiche per lo sviluppo

## Selezione Workflow
- Focus primario: Ricerca
- Giustificazione: Necessità di raccogliere informazioni ampie da fonti multiple per informare decisioni di sviluppo

## Metodologia
1. Analisi browser della web app target
2. Ricerca API finanziarie con focus su limiti e funzionalità
3. Ricerca accademica su teoria del portafoglio moderno
4. Valutazione comparativa di tecnologie frontend
