# Piano di Sviluppo: Piattaforma di Investimenti Completa

## 🎯 Obiettivo
Creare una web application completa per analisi, previsioni e gestione investimenti con dashboard personale, analisi approfondite e portfolio management avanzato.

- [x] [Research Step] Studiare l'algoritmo di Markowitz per l'ottimizzazione del portafoglio

### Fase 2: Progettazione
- [x] [Process Step] Definire l'architettura della piattaforma e le tecnologie da utilizzare
- [x] [Process Step] Progettare il database per gestire utenti, investimenti e portfolio

- [x] [Website Development Step] Creare le schede per analisi approfondite di strumenti finanziari

### Fase 4: Portfolio Management
